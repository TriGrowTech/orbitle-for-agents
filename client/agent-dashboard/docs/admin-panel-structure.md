CORE ADMIN PANEL STRUCTURE (Simplified)

Here is the realistic MVP admin panel structure:

Dashboard
Branding & Site Settings
Packages
Leads & Enquiries
Banners & Promotions
Content Sections
Testimonials
SEO & Analytics
Users & Permissions (later)

Now let’s go section by section and keep only the most important editable fields.

🧭 1. DASHBOARD (Overview only)

This is the home screen after login.

Show:

Total leads this month
WhatsApp clicks
Package enquiries
Top performing packages
Recent enquiries list

No editing here. Only stats.

🎨 2. BRANDING & SITE SETTINGS (Most Important)

This replaces Topbar + Navbar + Footer + Theme + Global Settings.

🟢 Company Info

Agents ALWAYS need this editable.

Fields:

Company name
Logo upload
Phone number
WhatsApp number
Email address
Office address
Social links (FB, Insta)
🎨 Theme Settings (Keep VERY small)

Don’t give 20 colors. Only:

Primary color
Accent color
Light/Dark mode toggle

That’s enough to change entire site.

🌐 Basic Site Settings
Currency (₹ / $ / AED)
Timezone
Default WhatsApp message

👉 This single section replaces 6 giant sections from your list.

🎁 3. PACKAGES (THE HEART OF BUSINESS)

This is the MOST used part of the panel.

Package List Page
Add package
Edit package
Delete package
Toggle Active/Inactive
Package Fields (Essential Only)
Basic Info
Package name
Destination
Duration (Days/Nights)
Starting price
Discount price (optional)
Category
Domestic
International
Trending
Media
Featured image
Image gallery
Highlights
Short description (3–4 lines)
Highlights bullet points
Inclusions

Simple toggles:

Hotel
Meals
Transport
Sightseeing
Itinerary

Rich text editor (single field)

Lead Settings
WhatsApp prefilled message

That’s it.
Do NOT give 50 package fields initially.

📥 4. LEADS & ENQUIRIES (CRITICAL)

This is the money section.

Fields to store automatically:

Name
Phone
Email (optional)
Destination interest
Travelers
Budget
Date
Source (Hero form / Package page / Popup)

Admin actions:

View lead
Mark as contacted
Delete lead

Optional later:

Export CSV
🎪 5. BANNERS & PROMOTIONS

This replaces Hero + Ad Ribbon.

Agents LOVE running offers.

Fields:

Banner image
Banner title text
Button text
Button link (WhatsApp / package)
Active toggle
Display order

That’s all.

No autoplay speed, overlay opacity etc.

🧩 6. CONTENT SECTIONS (Simplified CMS)

This controls homepage sections.

Travel Themes

Fields per theme:

Theme name
Theme image
Link to packages
Active toggle
Why Choose Us

4 cards only:

Title
Description
Icon
FAQ
Question
Answer

Keep it minimal.

⭐ 7. TESTIMONIALS

Very important for conversions.

Fields:

Customer name
Photo
Review text
Rating
Destination
📈 8. SEO & ANALYTICS

Only the important fields:

SEO
Site meta title
Site meta description
OG image
Tracking
Google Analytics ID
Facebook Pixel ID

That’s enough.
